

## Phase 11: Real-time Chat Application

### Starting the Backend
1. Open a terminal and navigate to the project root.
2. Run py -3.10 backend/main.py
3. The backend API will start on http://localhost:8001.

### Starting the Frontend
1. Open the file rontend/chat.html directly in any modern web browser.
2. It will automatically connect to the backend running on port 8001.
3. (Alternatively, you can run python -m http.server 3000 in the frontend directory and visit http://localhost:3000/chat.html).

### Features Included
- Real-time Emotion Detection
- Intelligent User Memory (Fact Extraction & Contextual Retrieval)
- Adaptive Conversational AI with Safety checks
- Beautiful Glassmorphism UI
